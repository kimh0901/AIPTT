## 五個步驟

### 步驟 1　選擇情境

- **定期更新型**：每月固定要交的報告，例如用電數據月報
- **臨時交辦型**：主管突然要的對比分析
- **我自己的題目**：手上任何資料都可以

前兩個已經內建課程的練習素材，點下去就會自動帶入。

### 步驟 2　準備素材

課程範例已經填好，可以直接用。要換成自己的資料有兩種方式：

- 把檔案拖進虛線框（支援 Word、PDF、Excel、CSV、純文字）
- 直接在框裡貼上或修改文字

上傳 Excel 或 CSV 時，系統會先在你的電腦裡把合計、平均、前三名算好，再交給 AI，避免 AI 自己加總算錯。

### 步驟 3　建立規範 Rules

這是整堂課的重點。填入：

- 角色設定與目標受眾
- 總頁數
- 頁標題幾個字以內
- 核心結論幾個字以內
- 每頁最多幾點、每點幾個字
- 禁用哪些模糊形容詞

下方會即時顯示這些設定組合成的完整指令。這份規範會存在你的瀏覽器，下次打開自動帶入。

**建議試一次**：把「頁標題字數」從 15 改成 8，或把禁用詞清空，再跑一次，比較前後差異。這是最能體會規範作用的方式。

### 步驟 4　取得大綱

1. 按「**複製指令**」
2. 貼到你平常在用的 ChatGPT、Gemini、Claude 或 NotebookLM（免費帳號就可以）
3. 把 AI 回覆的內容整段複製，貼回平台下方的框

貼進去後下面會顯示「✓ 抓到 3 頁：⋯⋯」，代表讀取成功。沒有出現就檢查是不是只貼到一部分。

平台認得各種寫法，`#` 標題、粗體標題、「第 1 頁：」開頭、編號清單都可以，不必要求 AI 用特定格式。

### 步驟 5　選擇設計風格

六種風格挑一個，右邊有即時預覽。換風格不會影響內容。

## 完成之後

進入編輯區可以：

- **直接點畫面上的文字修改**，改完自動存
- 左側調整頁面順序、複製、刪除
- 右側輸入指令重寫某一頁（需要有設定模型）
- 上方「演示」進入全螢幕播放，方向鍵翻頁

匯出有四種：

| 格式 | 用途 |
|---|---|
| **可編輯 PPTX** | 下載後用 PowerPoint 開啟，每個文字方塊都能改，講稿在備忘稿 |
| 簡報 HTML | 單一檔案，方向鍵翻頁，按 P 可列印成 PDF |
| Markdown 大綱 | 交給其他工具接手排版 |
| 專案 JSON | 帶到別台電腦接著改 |

## 常見問題

**需要 API 金鑰嗎？**
不需要。第四步用你自己的 AI 帳號就好。如果想在平台上直接按一下生成，可以到右上角「設定」填一組 Google Gemini 免費金鑰（aistudio.google.com/apikey，不用信用卡）。

**資料會傳到哪裡？**
不會傳到任何地方。素材、規範、簡報內容全部只存在你自己的瀏覽器。

**關掉分頁內容會不見嗎？**
不會，會自動保留。但清除瀏覽器資料或換電腦就沒了，重要的簡報請用「匯出專案 JSON」備份。

**匯出 PPTX 失敗？**
需要連得上網路載入打包程式庫。如果一直失敗，改用「匯出簡報 HTML」再從瀏覽器列印成 PDF，或聯絡承辦人。

**PDF 讀不出內容？**
掃描檔（純圖片的 PDF）沒有文字層，讀不出來。請改用可以選取文字的 PDF，或直接複製貼上。
